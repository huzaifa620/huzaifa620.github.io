# huzaifa620.github.io

Personal site of Muhammad Huzaifa, Software Engineer (mobile, full-stack and AI): https://huzaifa620.github.io

Hand-written HTML, CSS and vanilla JavaScript in `site/`. No framework and no build step. Pushing to `main` checks that every local link resolves, then publishes `site/` to the `gh-pages` branch.

Run locally: `python -m http.server 8765 --directory site`, then open http://127.0.0.1:8765.

The previous Jekyll site is kept on the `jekyll-archive` branch.
